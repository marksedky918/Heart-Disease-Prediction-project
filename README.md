# Heart Disease Prediction ❤️

A Machine Learning project developed during our **AI Internship at Samsung Innovation Campus**, in collaboration with **Life Makers Foundation**.

## 📌 Project Overview

The goal of this project is to predict whether a patient has heart disease based on different medical features.

## 🔍 Project Workflow

* Data Cleaning & Preprocessing
* Exploratory Data Analysis (EDA)
* Feature Engineering
* Model Training
* Model Comparison
* Model Evaluation

## 🤖 Machine Learning Models

We trained and compared several models:

* Logistic Regression
* Random Forest
* SVM
* KNN
* Gradient Boosting
* XGBoost
* Decision Tree

## 📊 Evaluation

We used several evaluation metrics:

* Accuracy
* Precision
* Recall
* F1-Score
* ROC-AUC

Since this is a heart disease prediction problem, **Recall and F1-Score** were especially important because missing a patient with heart disease can be more serious than incorrectly predicting heart disease for a healthy patient.

## 🏆 Final Model

After comparing and tuning the models, **Gradient Boosting** was selected as our final model.

* **F1-Score:** 0.909
* **Recall:** 0.931
